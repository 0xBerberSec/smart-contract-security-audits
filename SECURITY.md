# Security Policy

This repository is a public security research portfolio.

## Reporting Issues

For a non-sensitive factual correction or broken link, a GitHub issue or pull request is appropriate. Do not include confidential source code, credentials or undisclosed vulnerability details in a public issue.

## Scope

This selection contains an official competition outcome, audit methodology, testing practices and generic investigation overviews. No runnable protocol PoC is included. See the [evidence register](docs/EVIDENCE.md) for the exact claims and their limits.

It does not operate production systems or hold user funds.

## Responsible Disclosure

Report protocol vulnerabilities through the affected project's official security process and applicable program terms. This portfolio is not an intake channel for another protocol's private findings.

Technical publication requires an established disclosure basis for the exact content. Prior self-publication or an assumed fix is insufficient. See the [disclosure policy](docs/DISCLOSURE.md).
