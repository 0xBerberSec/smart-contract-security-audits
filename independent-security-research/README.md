# Independent Security Research

My independent work examines accounting assumptions, authorization boundaries and state transitions. Local evidence can establish a specific behavior without establishing production exploitability or external acceptance.

Technical studies whose disclosure rights are unresolved are excluded from this public selection. There are no private reports or source links on this page, and no unpublished finding is presented as third-party validated.

For a disclosure-safe explanation of the reasoning, read the [investigation overviews](../protocol-investigations/README.md). For the evidence threshold, read the [validation process](../methodology/validation.md).
